# Sun of Egypt 3 landing page

Open `dist/index.html` to preview the page.

## Files

- `dist/index.html` — page content and offer link
- `dist/styles.css` — desktop and mobile styling
- `dist/assets/` — optimised website artwork
- `source-images/` — full-resolution PNG artwork, including one alternative hero

The Join Now destination can be changed in the `href` on the main CTA inside `dist/index.html`.
